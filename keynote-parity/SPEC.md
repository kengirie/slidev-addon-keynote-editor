# Keynote の操作仕様（実機で測ったもの）

Keynote 14.4（macOS、日本語 UI、テーマ「ベーシックホワイト」、1920×1080、表示 78%）を
`kn.py`（CGEvent でマウス、System Events でキー、AppleScript で結果の座標と文字を読む）で操作して確かめた。
テストスクリプトは `t*.py`。

## 選択と文字編集（プレースホルダー）

| 操作 | Keynote の結果 | テスト |
|---|---|---|
| 選んでいない枠の文字の上を 1 回クリック | **枠が選ばれる**（8 個のハンドル、青い枠線）。カーソルは出ない | t2 |
| 選んでいない枠の空き領域をクリック | 枠が選ばれる | t2 |
| 選ばれている枠の文字をもう 1 回クリック | **文字編集**に入る。クリックした位置にカーソル。ハンドルは消え、枠線は灰色 | t2 |
| 選んでいない枠の文字をダブルクリック | 文字編集に入り、**単語が選択**される（打つと単語が置き換わる） | t8-B |
| 文字編集中に ⌘Return | **枠の選択に戻る**（ハンドルが出る） | t3 |
| 文字編集中に Esc | **選択がすべて外れる**。文字は編集したまま残る（取り消しではない） | t3 |
| 枠を選んだ状態で文字を打つ | 枠の中身が**まるごと**打った文字に置き換わり、文字編集に入る | t3 |
| 選んでいない枠の文字の上からドラッグ | 選択と同時に**枠ごと移動**する | t8-A |
| 空のプレースホルダー | 編集画面では案内文（例：「スライドのサブタイトル」）が**本物の文字と同じ色・書式**で表示され、枠線（薄い灰色）も出る。書き出し・再生では出ない | t2, t8-C, 書き出し PNG |
| 空のプレースホルダーをクリックして文字を打つ | 案内文が打った文字に置き換わる | t8-C |
| スライドの何も無い所をクリック | 選択が外れる | t2 |

## 移動・サイズ変更

| 操作 | Keynote の結果 | テスト |
|---|---|---|
| ドラッグ | 動かした量だけ移動。そのスライドだけが変わり、マスターは変わらない | t1, t4 |
| 矢印キー | **1pt** 移動 | t4 |
| Shift+矢印キー | **10pt** 移動 | t4 |
| 右下のハンドル | 幅と高さを自由に変える（テキストの枠は縦横比固定ではない） | t4 |
| Shift+右下のハンドル | **縦横比を保つ**（1730×650 → 1626×611） | t4 |
| Option+右下のハンドル | **中心を基準**に変える（左上も動く：95,335 → 195,385、1530×550） | t4 |
| 右辺のハンドル | 幅だけ変わる | t4 |
| ⌘ を押したままドラッグを始める | 枠は動かない（⌘クリック＝選択の切り替えになる） | t6-d |
| Delete（枠を選択中） | プレースホルダーそのものが消える | t4 |
| フォーマット ＞「選択内容にレイアウトを再適用」 | 選んだ枠だけがレイアウトの既定の位置・大きさに戻る（95,335,1730,650） | t4 |

## 吸着とガイド

| 項目 | Keynote の結果 | テスト |
|---|---|---|
| スライド中央への吸着 | 中心がスライド中央から **±8pt 以内（表示 78% で画面約 6px）** なら吸着、10pt では吸着しない | t5 |
| 他のオブジェクトの中心への吸着 | 中心どうしが揃う位置に吸着する（タイトル中心 141、サブタイトル中心 224 に吸着。縦方向も同じ） | t10 |
| 端への吸着 | **しない**（他のオブジェクトの端、スライドの端とも。初期設定） | t9 |
| サイズ変更中の吸着 | **しない** | t11 |
| ⌘＋ハンドルのドラッグ | 中心を軸に回転（押した位置からの角度の変化だけ回る）。Shift で 45° 刻み | t12 |
| 吸着のタイミング | ドラッグ中に吸着し、ガイドが出る（離した位置ではなく、動かしている間に吸い付く） | t7 |
| ガイドの見た目 | **1px の黄色の線（#EDC32F）**、スライドの端から端まで | t7 |
| 位置の表示 | ドラッグ中、カーソルの近くに「**x: 560 pt  y: 364 pt**」（黒い角丸のラベル、枠の左上の座標） | t5, t7 |
| 選択の見た目 | 枠線は 1px の淡い青（#8FB2FC）、ハンドルは 7px の白い四角に 1px の黒い縁。回転ハンドルは無い | 実測 |
| 空のプレースホルダーの枠線 | 画面上 1px の #CCCCCC | 実測 |

## 再生・書き出し

- 空のプレースホルダーは表示されない（案内文も枠線も出ない）

## エディタ（slidev-addon-keynote-editor）での結果

`web/p*.mjs` で Slidev のブラウザを操作し、Keynote と同じ条件で比べた（Keynote のテーマ、1920×1080）。

| 操作 | Keynote | エディタ |
|---|---|---|
| 選んでいない枠の文字をクリック | 枠を選択 | 枠を選択 ✓ |
| もう 1 回クリック | 文字編集・クリック位置にカーソル | 同じ ✓ |
| ⌘Return / Esc | 枠の選択に戻る / 選択なし | 同じ ✓ |
| ダブルクリック | 単語「スライド」を選択 | 単語「スライド」を選択 ✓ |
| 枠を選んで文字を打つ | 中身が置き換わる | 同じ ✓ |
| 空のプレースホルダーに打つ | 案内文が置き換わる | `::subtitle::` が追加される ✓ |
| 文字の上からドラッグ +100,+50 | 195,385 | 195,385 ✓ |
| → / ⇧→ / ⇧↓×2 | +1 / +10 / +20 | 同じ ✓（スライドは送られない） |
| 右下ハンドル −100,−50 | 1630×600 | 1630×600 ✓ |
| ⇧＋右下ハンドル | 1626×611 | 1626×611 ✓ |
| ⌥＋右下ハンドル | 195,385,1530,550 | 195,385,1530,550 ✓ |
| ⌘＋ハンドルで回転 / ⇧ 付き | 8°（Keynote 表記 352°）/ 0° | 8° / 0° ✓ |
| 中心の吸着（+4, +8 / +10） | 吸着 / しない | 同じ ✓ |
| 端の吸着 | しない | しない ✓ |
| 選択内容にレイアウトを再適用 | 既定の位置に戻る | 戻る（`dragPos.<名前>` を削除）✓ |
| Delete | プレースホルダーが消える | 非表示（`boxes.<名前>.hide`）。チェックボックスや再適用で戻せる |
| ⌘Z / ⇧⌘Z | 元に戻す / やり直す | 同じ ✓ |

違い：Keynote の Delete は中身ごと消すが、エディタは中身を Markdown に残したまま非表示にする（Markdown が正本なので、消すと戻せない）。
